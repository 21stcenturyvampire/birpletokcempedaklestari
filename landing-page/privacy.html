Kebijakan Privasi

Berlaku sejak 11 November 2026

Halaman ini menjelaskan data apa yang dikumpulkan dan digunakan oleh website Bir Pletok Cempedak Lestari ("kami") beserta aplikasi internal pengelolaannya, termasuk integrasi dengan Google Drive.

1. Pengunjung website

Website publik ini hanya menampilkan informasi produk, lokasi, dan kontak. Kami tidak meminta pengunjung mendaftar, tidak memasang cookie pelacak atau iklan, dan tidak mengumpulkan data pribadi pengunjung. Saat kamu menekan tombol WhatsApp atau tautan media sosial, kamu berpindah ke layanan pihak ketiga tersebut dan tunduk pada kebijakan privasi mereka.

2. Aplikasi internal

Aplikasi internal hanya dipakai oleh pengelola usaha (Super Admin & Editor) untuk mencatat transaksi keuangan, persediaan barang, inventaris, dan jadwal konten. Data yang disimpan: nama dan email akun pengguna, serta data operasional usaha yang mereka input. Data disimpan di database Supabase dan tidak dijual atau dibagikan kepada pihak lain.

3. Integrasi Google Drive

Aplikasi "BPCL Laporan" menggunakan Google Drive API dengan izin drive.file untuk satu keperluan saja: setiap awal bulan, membuat file PDF laporan transaksi keuangan bulan sebelumnya dan mengunggahnya ke folder Google Drive milik pengelola usaha.

  • Aplikasi hanya dapat mengakses file dan folder yang dibuatnya sendiri, tidak dapat membaca, mengubah, atau menghapus file lain di Google Drive.
  • Data dari Google tidak disimpan di luar Google Drive, kecuali tautan ke file laporan yang dicatat di aplikasi internal agar mudah dibuka.
  • Data dari Google tidak dibagikan, dijual, atau dipakai untuk iklan maupun pelatihan model AI.
  • Penggunaan data yang diterima dari Google API mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.
  • Akses dapat dicabut kapan saja melalui pengaturan akun Google.

4. Keamanan

Akses aplikasi internal dilindungi login, dan setiap pengguna hanya bisa melihat atau mengubah data sesuai perannya. Kunci akses layanan disimpan sebagai rahasia terenkripsi, tidak di dalam kode program.
